# מלט ומספרים

דוח מצב כלכלי יומי — נדל"ן, שווקים ומאקרו.

אתר סטטי המארח את הדוח הכלכלי היומי בעברית — נדל"ן ישראל, נדל"ן עולמי, שווקים ומאקרו.
מיועד ל-GitHub Pages: אין תלות בשרת, בבנייה או ב-npm.

## מבנה

```
index.html          עמוד הבית — תמיד הדוח האחרון
archive.html        רשימת כל הדוחות, מהחדש לישן
YYYY-MM-DD.html     קישור קבוע לכל דוח יומי
assets/style.css    עיצוב משותף (RTL, מובייל, מצב כהה, הדפסה)
assets/site.js      מתג מצב כהה/בהיר עם שמירה בדפדפן
.nojekyll           מונע מ-Jekyll לעבד את הקבצים
publish.sh          הוספת דוח חדש + עדכון הארכיון + push
```

## הפעלה ראשונית

```bash
git remote add origin https://github.com/<user>/<repo>.git
git push -u origin main
```

לאחר מכן ב-GitHub: **Settings → Pages → Source: Deploy from a branch → main → / (root)**.
תוך דקה-שתיים האתר עולה בכתובת `https://<user>.github.io/<repo>/`.

## פרסום דוח חדש

```bash
./publish.sh דוח-כלכלי-2026-08-03.html 2026-08-03 "כותרת קצרה של היום"
```

הסקריפט מעתיק את הדוח לקישור הקבוע ולעמוד הבית, מוסיף שורה בראש הארכיון,
ומבצע commit ו-push. האתר מתעדכן אוטומטית.

## הערות

- כל עמוד דוח עצמאי מבחינת תוכן, ומושך עיצוב מ-`assets/style.css`.
- מצב כהה עובד אוטומטית לפי העדפת המערכת, וניתן לעקוף ידנית בכפתור בסרגל.
- כל עמוד מוכן להדפסה: סרגל הניווט נעלם וההדפסה יוצאת נקייה.
- הדוחות כוללים קישור למקור לכל נתון. 🔒 מסמן כתבה מאחורי חומת תשלום.

אין באמור ייעוץ השקעות, ייעוץ פיננסי או המלצה לפעולה.
